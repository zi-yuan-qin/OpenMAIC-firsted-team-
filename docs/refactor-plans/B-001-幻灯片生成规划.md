# B-001 幻灯片生成 — 开发规划

> 任务编号: B-001 | 负责人: 队员2 | 状态: ✅ 已完成

## 需求

输入教学主题，AI 自动生成课程幻灯片 JSON。复用现有 slide-content.md 提示词模板，单次 AI 调用生成整份幻灯片（非逐页生成）。

## 架构设计

```
POST /api/sky/slides/generate
  │ { topic, difficulty?, slideCount?, language? }
  │
  ├─ resolveModelFromRequest() → LanguageModel
  ├─ 构建 aiCall = async (system, user) => callLLM(...).text
  │
  └─ generateSlides(topic, options, aiCall)
       ├─ buildPrompt(SLIDE_CONTENT_V2, {...}) → system prompt
       ├─ 构建 user prompt（多页 slides 数组 JSON 输出指令）
       ├─ aiCall(system, user) → parseJsonResponse
       └─ 逐页组装 Slide（fixElementDefaults + 默认主题）
```

## 关键设计决策

1. 复用 `PROMPT_IDS.SLIDE_CONTENT_V2` 模板作为 system prompt
2. 依赖注入 `AICallFn`，API route 负责构建 `callLLM` 包装器
3. 难度 → 页数映射: junior=6, senior=8, college=12
4. 默认主题: 白色背景, Microsoft YaHei 字体, 5 色主题色板
