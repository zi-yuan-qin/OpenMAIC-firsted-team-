# B-002 虚拟形象讲解 — 开发规划

> 任务编号: B-002 | 负责人: 队员2 | 状态: ⬜ 待验收

## 需求

为每张幻灯片生成讲解脚本，调用 TTS 合成语音，实现文字逐句高亮播放。复用现有 `generateTTS()` 管线，3 种虚拟形象配置。

## 架构设计

```
POST /api/sky/slides/avatar-speak
  │ { slides, avatarId, speed? }
  │
  ├─ getAvatarById(avatarId) → AvatarConfig
  ├─ 构建 ttsGenFn 闭包（server credential 注入 + generateTTS）
  │
  └─ generateAvatarSpeech(slides, avatarId, ttsGenFn, options)
       ├─ extractTextFromSlides → 纯文本
       ├─ splitSentences → 句子数组
       ├─ 逐句 TTS（并发 3）
       └─ 返回 AvatarSpeech { avatarId, segments }
```

## 关键设计决策

1. 不需要 AI 生成脚本 — 幻灯片文字已由 B-001 生成
2. 依赖注入 `TTSGenerateFn` — 测试用 mock，生产用 `generateTTS`
3. 3 个虚拟形象使用 VoxCPM（无需 API key）
4. 逐句分割为高亮播放设计
5. 单句 TTS 失败优雅降级（audioUrl = 空）
